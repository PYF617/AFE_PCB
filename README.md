# Analogue Frontend PCB for MSc Microelectrode Fabrication Project

This is a 16-channel Intan RHD2216 AFE implemented as a shield for the NUCLEO-H723ZG STM32 development board.

This PCB contains:
- Intan RHD2216 16-channel differential AFE IC
- Clean 3V3 VDD Supply
- Actively driven guard electrode
- Microelectrode and reference input protection
- 16-channel ZIF connector
- Isolated field stimulator synchronisation input/output
- ST Morpho connectors
